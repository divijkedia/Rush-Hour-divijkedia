# Notebooks

Keep your exploration and experiments here: data exploration, model comparison, threshold experiments, and any quick analysis behind a claim in your report.

Tips:

* Name notebooks so the order is obvious, for example `01_explore_data.ipynb`, `02_model_comparison.ipynb`.
* Clear heavy outputs before committing, so the repository stays small.
* Anything that produces a final number for your report should also be reproducible from `code/`, because judges run the code, not your notebooks.
